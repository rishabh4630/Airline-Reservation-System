# Airline Reservation System

## Project Overview
The Airline Reservation System is a software application developed using Visual Basic .NET. It is designed to manage airline reservations and provide a simple interface for handling flight-related operations.

## Features
- Flight Management
- Flight Scheduling
- Passenger Reservation Management
- Cancel Reservations
- Ticket Printing
- Refund Receipt Printing
- Sector Management
- Database Integration

## Technologies Used
- Visual Basic .NET
- .NET Framework
- Visual Studio
- Database (see the `Database` folder)

## Project Structure
- `HorizonApp.sln` – Visual Studio solution file
- `HorizonApp.vbproj` – Project configuration
- `.vb` files – Application source code
- `.resx` files – Form resources
- `Database/` – Database-related files

## How to Run
1. Download or clone this repository.
2. Open `HorizonApp.sln` in Visual Studio on a compatible Windows environment.
3. Restore any required project dependencies.
4. Check the database configuration and connection settings.
5. Build and run the project.
